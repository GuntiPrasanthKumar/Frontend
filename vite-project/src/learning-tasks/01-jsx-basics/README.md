# Topic 01: JSX Basics & Conditional Rendering

## Learning Objectives
- Understand JSX syntax rules and differences from plain HTML.
- Embed JavaScript expressions inside curly braces `{}`.
- Use React Fragments (`<></>` or `<React.Fragment>`) to prevent unnecessary DOM nodes.
- Implement conditional rendering via ternary operators (`condition ? a : b`) and short-circuit evaluation (`condition && <Component />`).

## Practice Task
Create a dynamic greeting card component that shows different badges and greetings based on user login status and notification count.
